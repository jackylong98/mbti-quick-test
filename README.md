# MBTI 快测 (MBTI Quick Test)

轻量级 MBTI 人格趣味测评网页 —— 打开即测、2 分钟出结果、免登录、数据不出设备。

## 在线使用

https://jackylong98.github.io/mbti-quick-test/

## 功能

- 20 道自研二选一题目，覆盖 E/I、S/N、T/F、J/P 四维度
- 上一题 / 下一题导航，进度条实时显示
- 16 型结果 + 四个字母含义 + 简短特点说明
- 前端 Canvas 生成分享卡片，微信长按即可保存转发
- 历史记录本地留存（localStorage），可回看、可清空

## 项目文档（docs 目录）

- SPEC_MBTI.md / SPEC_MBTI.docx —— 需求规格说明书
- PRD_MBTI.docx —— 产品需求文档
- prototype.html —— 交互原型（手机壳 + PRD 标注层）

## 声明

本测评仅供娱乐和自我了解，不构成心理诊断或专业建议。
