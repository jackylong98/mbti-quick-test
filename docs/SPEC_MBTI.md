# SPEC — MBTI 性格测评程序（个人娱乐向网页工具）

> 版本：v1.0 ｜ 定稿日期：2026-09-15 ｜ 状态：已收敛，待确认后开发
> 需求收敛方式：苏格拉底式十问十答，决策记录见附录 A。

---

## 1. Problem Statement（问题陈述）

MBTI 在社交与娱乐场景热度高，但现有渠道两极分化：

- **官方测评**：专业但收费高、题量大（93 题起），个人娱乐场景门槛过高；
- **散装 H5 小测试**：题目质量参差、动辄几十题、界面粗糙、常要求关注公众号或授权个人信息，体验被打断。

缺少一个「**打开即测、2–3 分钟出结果、免费无打扰、结果可保存分享**」的轻量娱乐工具。

## 2. Proposed Solution（方案描述）

做一个**纯前端静态网页应用**：

- 用户打开即测，无需注册登录；
- 作答 **16–20 道自研题目**（二选一），浏览器本地计分，判定 16 型人格之一；
- 结果页展示**极简报告**：类型字母 + 类型名 + 一段描述；
- 一键**生成结果卡片图**，保存/转发到微信；
- 历次结果保存在**浏览器本地（localStorage）**，可回看、可清空。

全程无后端、无数据库、无账号，数据不出设备。

## 3. Target Users（目标用户）

- **主用户**：对 MBTI 感兴趣的普通个人，动机为自我探索、社交谈资、娱乐消遣。
- **典型链路**：朋友圈看到他人结果卡片 → 点链接 → 手机浏览器/微信内置浏览器打开 → 2–3 分钟完成 → 保存卡片 → 转发。

## 4. Core Features（核心功能）

| # | 功能 | 说明 |
|---|------|------|
| F1 | 测评流程 | 欢迎页 → 逐题作答（二选一、进度条、可回退上一题）→ 结果页 |
| F2 | 计分判定 | E/I、S/N、T/F、J/P 四维度独立计分，组合判定 16 型之一 |
| F3 | 极简结果报告 | 类型字母（如 INFP）+ 类型名 + 一段描述，无维度百分比图 |
| F4 | 结果卡片图 | 前端 Canvas 生成分享图：类型 + 一句话概括 + 日期，可保存/长按转发 |
| F5 | 本地历史记录 | localStorage 存储历次结果（日期 + 类型），支持回看与一键清空 |
| F6 | 自研题库 | 16–20 题内置于前端（JS 数组），四维度各 4–5 题，题目自研规避官方版权 |

## 5. Technical Constraints（技术约束）

- **架构**：纯前端静态页（HTML/CSS/JS），零后端、零数据库、零运维；本地双击或任意静态托管即可运行。
- **实现**：优先原生实现、零外部依赖（不用 CDN 框架）；卡片生成优先原生 Canvas。
- **兼容**：微信内置浏览器、主流手机浏览器（Chrome/Safari）、桌面浏览器；移动优先、响应式布局。
- **隐私**：除用户主动保存/转发卡片外，无任何网络请求，测评数据不出设备。
- **规模**：单页应用，题库 + 文案全部内置，总体积控制在数百 KB 量级。

## 6. Non-goals（明确不做的事）

1. 无账号体系 / 登录 / 手机号收集
2. 无后台管理端
3. 无团队 / 群像报告
4. 不用于招聘、心理咨询等任何专业场景
5. 不做 AI 解读 / 个性化追问
6. 不付费、无广告、无商业转化
7. 不追求专业测量信效度（重测一致性、常模等）——仅供娱乐与自我探索

## 7. Success Criteria（成功标准）

1. **打开不乱**：微信内置浏览器 / 手机浏览器 / 桌面浏览器打开均正常显示，加载快（本地或静态托管下首屏秒开）。
2. **3 分钟完成**：新手不看任何说明，可在 3 分钟内走完测评为出结果。
3. **卡片可分享**：结果卡片图可保存到相册 / 转发到微信。
4. **历史不丢**：刷新或关闭后重开，历史记录仍在（用户主动清空除外）。
